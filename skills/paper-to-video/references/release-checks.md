# GitHub 分发检查

仅在准备分发或发布时读取。更新本地 skill 不等于获准创建公开仓库、推送或上传私人素材。

## 公共包的最小范围

可以分发本目录的 SKILL.md、references 与 scripts/project.py，作为带输入与证据检查工具的工作流型 skill。它能指导宿主 Agent 制作，但不包含通用一键视频引擎。安装时把完整 paper-to-video 目录放入宿主支持的 skills 目录；安装不提供云服务账户、字体、编码器或付费额度。

若同时分发代码，单独核验依赖、入口、平台路径、字体、TTS适配、示例可复现性与开源许可。不得给尚未实现的脚本写可运行示例，不得把依赖原环境内网服务的历史运行时间承诺给下载者。

## 发布前检查对象是实际分发包

- 不含私人论文、受限论文图、用户参考声音、克隆模型标识、音视频缓存、密钥、账户信息或本地绝对路径。
- 示例使用允许相应分发的来源，并保留所需署名；代码的许可证不自动覆盖论文和声音。
- 不依赖 .gitignore 作为唯一保密措施：检查实际暂存清单/压缩包成员；已追踪文件不会因为新增忽略规则自动移除。
- README 分开写“已经验证”“需要人工参与”“未实现”。独立审核、通用解析和跨平台运行没有测过就不打勾。
- 用至少一个新的、适合公开的测试样例验证端到端，再描述可复现能力。两篇定制视频不代表任意论文泛化。

## 验证 skill 本身

检查 frontmatter、所有相对引用、未完成占位和非公开信息。情境检查至少覆盖：仅改结构保留声音；改读音更新缓存与对齐；缺TTS不擅换声音；许可未知不自动公开；用户未授权不删旧版。

格式验证与这些情境检查都不等于已验证新的论文可以自动生成视频。发布前若仍缺统一 provider、CLI 或许可，应明确列出，而不是在本次文档更新中假称已经补齐。
